# Farfetch

Farfetch is an E-Commerce website anyone can buy products easily from our website.

Have a look ⬇️

## Tech Stack

- NodeJs
- React
- Redux
- Mongodb
- Express
- ChakarUI
- **Deploying:** vercel

## Features

- Responsiveness using Chakra UI
- list products
- Sign up Singn in
- Able to Book products
- Carousal Effect
- Tabs using Chakra UI
- Drawer using Chakra UI
- Drop-down using Chakra UI
